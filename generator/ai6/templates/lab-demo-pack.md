## 2. 四问选工具

1. 要做什么：短剧 / 15 秒短视频 / 产品 / 口播 / 品牌
2. 手上有什么：无独显 / 16GB / 24GB+
3. 每月预算：¥0–100 / ¥100–500 / ¥500+
4. 优先什么：速度 / 可控 / 原生音频

输出三张卡：

- 主选：按交付物和优先级先跑的一个组合
- 备用：动作、多人、音画或本地降本的第二组合
- 先别：当前条件下最容易烧钱或最容易失败的做法
