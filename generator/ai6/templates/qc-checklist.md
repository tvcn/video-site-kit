# 验收清单 / QC Checklist

## A. 内容（6 项）

- [ ] 5 秒内能看懂谁在做什么。
- [ ] 20 秒内能看懂冲突/卖点。
- [ ] 每条信息只出现一次；没有重复解释。
- [ ] 结尾有落点：选择/反转/行动，不是“就这样”。
- [ ] 没有与主题无关的装饰镜头。
- [ ] 字幕逐句校对：人名、数字、专业词无误。

## B. 画面（6 项）

- [ ] 角色在镜头间不换脸、不换年龄。
- [ ] 服装/配饰/发型连续。
- [ ] 光向一致（窗光从右，不突然从左）。
- [ ] 手部没有六指/粘连/穿模。
- [ ] 产品标签没有乱码/假字。
- [ ] 没有闪烁/重复帧/突然跳色。

## C. 声音（5 项）

- [ ] 对白清楚，手机外放能听。
- [ ] 口型与台词对齐；一句一镜。
- [ ] 环境声不断层。
- [ ] 音乐不盖对白。
- [ ] 响度 -14 LUFS，True Peak -1dB。

## D. 技术（5 项）

- [ ] 画幅 9:16 或 16:9，无黑边/拉伸。
- [ ] 1080×1920 或 1920×1080，30fps。
- [ ] 码率 8–12Mbps，暗部无块。
- [ ] 时长符合平台。
- [ ] 文件名：`项目_集数_版本_日期_平台_比例.mp4`。

## E. 合规（4 项）

- [ ] 肖像/声音/音乐/品牌/产品授权。
- [ ] AI 生成/数字人按平台标注。
- [ ] 没有未授权商标/影视片段。
- [ ] 没有隐私信息（门牌/手机号/聊天记录）。

## F. 交付包

- [ ] 成片 MP4
- [ ] 字幕 SRT
- [ ] 封面帧
- [ ] QC 表（本页）
- [ ] 授权/素材来源
- [ ] 工程文件/项目 JSON

## 打回规则

- A 任一项不过：重剪，不导出。
- B 脸/手/标签不过：重生成或改分镜，不靠后期硬修。
- C 对白/响度不过：重混，不靠平台自动增益。
- D/E 不过：不允许发布。
