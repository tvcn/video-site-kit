# 提示词包 / Prompt Pack

> 原则：一个镜头只做一件事。先写“谁、在哪、做什么”，再写光/镜头，最后写负面。不要堆形容词。

## 1. 对话镜头（5 秒）

```text
C01，中国女性，30 岁，黑色中长直发低马尾，灰色针织衫，坐在客厅木桌旁。
正面近景，固定机位，窗光从右，柔和。
她说：“你早就知道，对吧？” 一句，8–12 字。
5 秒，9:16，24fps，写实，低饱和。
负面：不要文字、不要logo、不要浓妆、不要镜头翻滚、不要过曝。
```

## 2. 动作镜头（5 秒）

```text
C02，中国男性，58 岁，灰白短发，深蓝工装衬衫，坐在客厅修收音机。
中景，固定机位，窗光从右。
动作只有一个：他放下螺丝刀，抬头看向门口。
5 秒，9:16，24fps，写实。
负面：不要多人、不要奔跑、不要换景、不要手部特写、不要文字。
```

## 3. 空镜/氛围（5 秒）

```text
一个安静的客厅，木桌，旧收音机，一杯热水，热气缓慢上升。
固定中景，轻微手持，窗光从右，真实质感。
5 秒，16:9，24fps。
负面：不要人物、不要文字、不要镜头翻滚、不要塑料感、不要过曝。
```

## 4. 产品微距（5 秒）

```text
产品 P01，磨砂玻璃瓶，米白标签，黑色无衬线字“MORNING”。
微距，标签朝镜头，缓慢推近，柔光箱从左，背景浅灰。
5 秒，9:16，24fps，写实。
负面：不要多余文字、不要反光过曝、不要手指、不要变形、不要logo。
```

## 5. 口播/数字人（10 秒）

```text
C01，正面中近景，坐姿，看镜头，自然说话。
背景：浅灰墙 + 一盆绿植，虚化。
光：柔光箱 45 度，眼神光。
台词：“先说结论：15 秒视频只需要一个卖点。” 分 2 句。
10 秒，9:16，30fps。
负面：不要侧脸、不要遮挡嘴、不要夸张表情、不要文字。
```

## 6. 负面词库

`文字, logo, 水印, 多余手指, 六指, 断肢, 穿模, 人脸变形, 年龄漂移, 镜头翻滚, 过曝, 塑料感, 低分辨率, 闪烁, 重复帧, 多人, 换景`
