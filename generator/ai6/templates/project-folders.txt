项目文件夹模板 / Project Folder Template
========================================

项目名示例：rain-letter

rain-letter/
├─ 00_script/          剧本、logline、90 秒节拍、Shot List
├─ 01_refs/            角色参考、场景参考、产品参考、道具参考
├─ 02_shots/           原始生成、草稿、废片、按镜头分文件夹
│  ├─ S01/
│  ├─ S02/
│  └─ ...
├─ 03_audio/           对白、TTS、音乐、音效、环境声
├─ 04_edit/            剪映/DaVinci 工程、字幕、导出预设
├─ 05_deliver/         成片、SRT、封面、QC 表、授权
├─ 99_archive/         旧版本、发票、聊天记录、授权原件
└─ project.md          一页项目说明：目标、预算、截止、参与人

命名规则
--------
镜头：项目_集数_镜头_版本_日期.mp4
示例：rain-letter_EP01_S05_v3_20261124.mp4
参考：C01_front_v1.png
交付：rain-letter_EP01_v3_20261124_douyin_9x16.mp4

版本规则
--------
v1 粗剪；v2 字幕/混音；v3 终版。
不要用“最终”“最终2”“真的最终”。
每次导出在 project.md 记一行：版本/日期/改什么/谁看/状态。

备份 3-2-1
----------
3 份：本机、移动硬盘、云盘。
2 种介质：SSD + 云。
1 份异地。
每周备份；交付后归档 99_archive，不删旧版。
