# QC Checklist (English)

## A. Content (6)

- [ ] Who does what is clear within 5s.
- [ ] Conflict/selling point clear within 20s.
- [ ] Each piece of information appears once; no repeated explanation.
- [ ] Ending lands on a choice/reveal/action, not "that's it".
- [ ] No decorative shots unrelated to the point.
- [ ] Captions proofed: names, numbers, technical terms.

## B. Picture (6)

- [ ] Same face/age across shots.
- [ ] Costume/accessories/hair continuous.
- [ ] Light direction consistent.
- [ ] No six fingers/fusion/clipping.
- [ ] Product label has no invented text.
- [ ] No flicker/repeated frames/color jumps.

## C. Sound (5)

- [ ] Dialogue clear on phone speakers.
- [ ] Lip sync holds; one line per shot.
- [ ] Ambience continuous.
- [ ] Music does not mask dialogue.
- [ ] -14 LUFS, true peak -1dB.

## D. Technical (5)

- [ ] Correct ratio, no black bars/stretch.
- [ ] 1080×1920 or 1920×1080, 30fps.
- [ ] 8–12Mbps, shadows not blocky.
- [ ] Length fits platform.
- [ ] File name: `project_episode_version_date_platform_ratio.mp4`.

## E. Rights (4)

- [ ] Likeness/voice/music/brand/product rights.
- [ ] AI/avatar disclosure per platform.
- [ ] No unlicensed trademark/film clip.
- [ ] No private information (door numbers/phone/chat).

## F. Delivery pack

- [ ] MP4
- [ ] SRT
- [ ] Cover frame
- [ ] This QC sheet
- [ ] Rights/source notes
- [ ] Project file/JSON

## Reject rules

- A fails: re-edit, do not export.
- B face/hand/label fails: regenerate or change the shot, do not "fix in post".
- C dialogue/loudness fails: remix, do not rely on platform auto-gain.
- D/E fails: do not publish.
