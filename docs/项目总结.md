# TVCN 项目总结

> 最后更新：2026-11-27
> 定位：项目负责人、编辑、技术复核看的**唯一当前状态总览**。本文与 `README.md`、`docs/AI交接文档.md` 同一口径；不再保留按日期分叉的旧总结。

## 1. 一句话结论

TVCN 现在是「**一份 Markdown 内容源 + 一套共享 UI + 按站分别构建**」的 9 站静态知识库：每个站只装本站文章，主站额外承担共享页与旧链接兼容页；正文只改 Markdown，构建自动重建索引、同步正文、跑完 QA 与审计；9 站已发布到线上并核验，仓库与本地目录已收口为「9 个站点仓 + 内容仓 + 构建仓」。

## 2. 项目是什么

- 主站 `https://tvcn.org/`：路径、方法、案例、工具卡、全站索引、主题、术语。
- 8 个分站：故事 `story`、拍摄 `shoot`、后期 `post`、AI `ai`、动画 `animation`、片型 `formats`、工具 `tools`、影像史 `context`。
- 全站中英双语，静态发布到 GitHub Pages，域名与证书走 Cloudflare。
- 内容原则：不伪造案例、不伪造测试、AI 图必须标注、来源不足写经验边界、不为凑数新增同质页面。

## 4. 架构

```text
content/                唯一内容源：506 对中英 Markdown、图解、来源
        +
site-kit/               共享 UI：article.css、shell、sites.json、UI 契约
        +
app/                    交互壳源文件（只发布到主站 /app/）
        +
assets/                 共享素材：封面、图解、音频、模板、图标
        +
generator/              构建：索引 → 正文 → 按站渲染/组装 → QA → 审计
        ↓
out/<site>/             每站只含本站文章、本站索引、本站搜索、引用资源
        ↓
deploy/<site>/          9 个发布工作副本（各自带 .git）
        ↓
GitHub Pages            9 个站点仓
```

四条硬规则：

1. **一篇文章只属于一个站**，以 `article.site` 为唯一归属。
2. **共享的是壳，不是正文**：CSS、页头页脚、导航、搜索组件共享；文章只进本站。
3. **canonical 自指**：每站文章 canonical 指向本站域名。
4. **正文只有一个来源**：Markdown。`generator/data/static-articles-data.json` 只是页面壳缓存，不手工编辑。

## 5. 站点边界

**主站**：77 对正文；22 个主题（46 页）、100 条术语、9 条路径、全站文章索引、about、搜索；`/app/` 交互壳；84 对旧 AI 兼容页（`noindex,follow`，canonical → `ai.tvcn.org`）；429 对非主站文章的旧 URL 兼容跳转页（`noindex`，canonical → 目标分站）。

**分站**：只发本站文章；只保留本站文章索引、本站搜索、404、CNAME、sitemap、引用资源；不发 about / glossary / paths / topics / `/app/`，页脚用绝对地址链接回主站。

**AI 站**：独立管线 `generator/ai6/`，49 个内容页 + 404，sitemap 47，不进入内容站构建器。

## 6. 构建与发布

```powershell
cd C:\Users\chenhua\Desktop\tvcn

# 全量构建：内容索引 → 正文同步 → 8 站 build+assemble → AI 站 → QA → 审计
node generator\build-all.mjs

# 单站
node generator\build-site.mjs --site=story
node generator\assemble-site.mjs --site=story

# 发布：先镜像到 deploy 并本地提交；加 -Push 才推送
powershell -ExecutionPolicy Bypass -File generator\publish.ps1 -Site story -Push
powershell -ExecutionPolicy Bypass -File generator\publish.ps1 -Site all -Push
```

`publish.ps1` 用 `out/<site>` 覆盖 `deploy/<site>`，保留 `.git`；不要直接改 `deploy/` 或 `out/` 当成源文件。

## 9. 本轮做完的事（2026-11-27）

1. **按站拆分**：8 个内容站只装本站文章；分站不再复制全站内容；`out/` 从 315MB 降到 61.1MB。
2. **旧链接兜底**：429 对非主站文章保留 `noindex` 跳转页；84 对旧 AI 页只留主站。
3. **正文单源**：`build-all.mjs` 自动跑索引与正文同步，改 Markdown 一条命令即可。
4. **页面结构清理**：修掉 190 页重复「边界」、46 页双 `article-body`、24 处重复正文小节、47 页重复 H2；计算器组件改为幂等（只挂一个）。
5. **审计收口**：入站链接改为扫 `out/`，意图簇改为读 `content/`，两者并入全量构建；外链 0 broken。
6. **仓库整理**：根目录建立仓库并推送到 `video-site-kit`；内容仓提交推送；修复 `.gitignore` 把 `generator/ai6/content/` 误当内容源忽略的问题。
7. **清理**：删除旧 `archive/`、8.5MB 基线 JSON、历史文档与按日期分叉的旧总结，本地从 468.3MB 降到 368.4MB。
8. **文档收口**：当前文档只保留 5 份，全部为无日期、唯一口径（本文 + 交接 + 部署 + 运营 + UI）。

## 10. 已知技术债与不做的事

**技术债**

1. 页面壳仍是整段 HTML 缓存：hero、封面、related、sources 的位置写在 `static-articles-data.json`；新增一对内容仍要加一条壳。下一步改为从 frontmatter + `sites.json` 渲染。
2. `deploy/` 的 Git 历史约 160MB，可评估压缩。
3. 尚未做 9 站全量视觉截图回归，只有 390/1280 烟测与页面抽查。
4. `generator/data/editorial-*.mjs` 里仍有旧增量文案，只在正文缺同名标题时补位；新内容不要再写进这些模块。

**明确不做**：Search Console、访问统计、Newsletter、真实联系表单、商业化/联盟/付费产品、为凑数新增同质页面。
