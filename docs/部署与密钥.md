# 部署与密钥

> 最后更新：2026-11-27。本文只管凭据、发布、Pages 与域名，不再记录历史发布日志。

## 1. 凭据放在哪

真实 token 只在项目外：

```text
C:\Users\chenhua\.config\tvcn\github.env
```

文件是三行纯文本，不是 `KEY=VALUE`：

```text
tvcn.org                      ← 第 1 行：站点域名
https://github.com/tvcn       ← 第 2 行：GitHub 账号地址
<40 位 classic PAT>           ← 第 3 行
```

实际读取方式是 `(Get-Content <path>)[2]`（第三行），并拼成 `x-access-token:<token>` 做 Basic 认证。**不要打印、不要复制进仓库、文档、HTML 或聊天。**

项目内只保留 `.env.example`（空值），真实文件永远被 `.gitignore` 排除。

## 2. 本地发布

```powershell
cd C:\Users\chenhua\Desktop\tvcn

# 只镜像到 deploy 并本地提交，不推送
powershell -ExecutionPolicy Bypass -File generator\publish.ps1 -Site story

# 推送（脚本自己读 token）
powershell -ExecutionPolicy Bypass -File generator\publish.ps1 -Site story -Push
powershell -ExecutionPolicy Bypass -File generator\publish.ps1 -Site all -Push
```

规则：

- 发布前必须先 `node generator\build-all.mjs` 通过。
- 先发一个分站做 canary（建议 story），再全量。
- `publish.ps1` 用 `out/<site>` 覆盖 `deploy/<site>`，保留 `.git`；默认只提交，`-Push` 才推。
- 不要手改 `deploy/` 或线上站点仓。

手动推内容仓或构建仓时，用一次性 header，不落盘：

```powershell
$tok = ((Get-Content "$env:USERPROFILE\.config\tvcn\github.env")[2]).Trim()
$auth = [Convert]::ToBase64String([Text.Encoding]::ASCII.GetBytes("x-access-token:$tok"))
git -c http.extraheader="Authorization: Basic $auth" push origin main
```

## 3. 仓库与 Pages

| 仓库 | 用途 | Pages |
|---|---|---|
| `tvcn/video-production-hub` 等 9 个 | 站点 | 开启，源为 `main` 根目录 |
| `tvcn/video-production-handbook` | 内容仓 | 不开 |
| `tvcn/video-site-kit` | 构建/共享仓 | 不开 |

- 9 个站点仓的 `CNAME` 分别是 `tvcn.org` 与 8 个二级域名。
- 自定义域名的 DNS 与 HTTPS 由 Cloudflare 维护。
- 改域名：先改仓库里的 `CNAME`，再改 Cloudflare DNS，最后确认 Pages 的 custom domain。

## 4. 发布后核验

```powershell
# 首页
foreach ($u in 'https://tvcn.org/','https://story.tvcn.org/','https://shoot.tvcn.org/','https://post.tvcn.org/','https://ai.tvcn.org/','https://animation.tvcn.org/','https://formats.tvcn.org/','https://tools.tvcn.org/','https://context.tvcn.org/') {
  "$u => " + (curl.exe -s -o NUL -w "%{http_code}" --max-time 25 $u)
}
```

必须确认：

1. 9 个首页 200。
2. sitemap 计数：main 210、story 100、shoot 104、post 112、animation 84、formats 132、tools 254、context 100、ai 47。
3. 抽文章页 canonical 为本站域名；分站抽查其他站 slug 为 404。
4. 主站旧 URL 兼容页 200 且跳转正确；旧 AI 页 `noindex`，canonical → `ai.tvcn.org`。
5. Pages 构建状态 `built`（`/repos/tvcn/<repo>/pages/builds/latest`）。

## 5. 故障处理

| 现象 | 处理 |
|---|---|
| 401 / 403 | 检查 token 行号与权限；classic PAT 需要 `repo`（建仓另需 `workflow`）。 |
| 连接重置 | 重试；仓库推送偶发，使用 `http.extraheader` 方式重试。 |
| Pages 一直 queued | 到仓库 Actions/Pages 面板重跑构建；检查 `CNAME` 与分支。 |
| 线上 404 但本地有 | 确认 `publish.ps1` 是否包含该站、`out/<site>` 是否最新、Pages 是否构建完成。 |
| 证书未生效 | Cloudflare 侧 DNS 与 SSL 模式；GitHub 侧 `https_enforced` 可按需开启。 |
