## 如果是 GitHub Actions

不需要把 PAT 放进文件。到仓库：

```text
Settings → Secrets and variables → Actions → New repository secret
```

新增 `GH_TOKEN`（或直接用 Actions 自带的 `GITHUB_TOKEN`）。Pages 部署通常只需要内置的 `GITHUB_TOKEN` 和以下权限：

```yaml
permissions:
  contents: read
  pages: write
  id-token: write
```

## Token 权限

- 只给目标仓库/组织最小权限。
- 需要建仓时：经典 PAT 的 `repo`；如果还要改 Actions，再加 `workflow`。
- 只做 Pages 上传：不要另建 PAT，用仓库自带 `GITHUB_TOKEN`。
- 不要把全账号、所有仓库的 admin token 放进来。

## 本地已有 GitHub CLI 时

最安全的是直接登录，不落文件：

```powershell
gh auth login
gh auth status
```

token 由系统的凭据存储管理，不写进项目。
