# TVCN 项目总结（2026-11-27）

> 文档定位：给项目负责人、编辑、技术复核和后续开发团队看的当前状态总览。本文以 **2026-11-27 按站拆分后的新结构**为准，不沿用旧 `v2/`、`build/pages-sites` 口径。

## 一句话结论

TVCN 已从“9 个站各自复制全站内容”改为“**一份 Markdown 内容源 + 一套共享 UI + 按站分别构建**”。每个分站现在只包含本站文章；主站只保留主站正文、全站共享页和旧链接兼容页。`out/` 从 315MB 降到 **61.1MB**，本地总体积从 1,032MB 降到 **368.4MB**，结构、归属、canonical、sitemap、资源、内链、入站链接与页面结构均已通过自动检查；正文只改 Markdown，构建会自动重建索引并同步正文。

## 1. 项目是什么

TVCN 是面向中文影像创作者的双语知识库：

- 主站 `https://tvcn.org/`：路径、方法、案例、工具卡、全站索引、主题与术语。
- 8 个分站：故事、拍摄、后期、AI、动画、片型、工具、影像史。
- 全站中英双语，静态发布到 GitHub Pages。
- 内容原则：不伪造案例、不伪造测试、AI 图必须标注、来源不足写经验边界、不为凑数新增同质页面。

## 3. 架构

```text
content/                    唯一 Markdown 内容源（506 对）
        +
assets/                     封面、图解、音频、模板、图标
        +
app/                        交互壳源文件（只发布到主站 /app/）
        +
site-kit/                   article.css、UI 契约、shell、sites.json
        +
generator/                  按站渲染、组装、QA、发布
        ↓
out/<site>/                 每站只含本站文章、本站索引、本站搜索、引用资源
        ↓
deploy/<site>/              9 个发布工作副本（带 .git）
        ↓
GitHub Pages                9 个站点仓
```

三条硬规则：

1. **一篇文章只属于一个站**，以 `article.site` 为唯一归属。
2. **共享的是壳，不是正文**：CSS、页头页脚、导航、搜索组件共享；文章只进本站。
3. **canonical 自指**：每站文章 canonical 指向本站域名。

## 5. 构建与 QA

### 构建

```powershell
cd C:\Users\chenhua\Desktop\tvcn
node generator\build-all.mjs
```

`build-all.mjs` 会：

1. 运行 `make-content-index.py` 重建内容索引；
2. 运行 `sync-static-bodies.py` 把正文渲染进页面片段缓存；

4. 构建 AI 站并复制到 `out/ai`；
5. 运行 `qa-sites.mjs`、`qa-links.mjs`、AI QA；
6. 运行入站链接审计与意图簇审计。
