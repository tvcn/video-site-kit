## 3. 每次复审的最小动作

1. 打开页面，确认标题、首段、结论没有过期。
2. 点开每条来源：`ok` 保留；`manual` 人工确认；`broken` 换源或删除。
3. 检查价格/型号/法规日期；改了就更新 `last_verified` 和 `review_due`。
4. 检查 3 条 related 是否仍分属不同子主题；失效的换掉。
5. 检查页面是否仍是孤岛：从 `/articles/` 和所属 topic 能否两次点击到达。
6. 在 `内容V1.1工作清单-2026-11-26.csv` 对应行写 `status=done` 和日期。

## 4. 过期处理

- 过期不等于删除。先标“待复审”，保留内容和 URL。
- 连续两个周期无人复审的页面，进入“合并/降级”候选：能并入主页面就并，不能并就降为经验说明。
- 任何删除、合并、301 都要单独确认；本计划不做 301。
